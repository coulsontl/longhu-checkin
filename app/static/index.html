添加账号

用手机号 + 验证码登录，不用抓包；之后 token 会自动续期，不会再过期。
填手机号 → 获取验证码（首次要拖一次滑块）→ 填验证码即可。登录拿到的 token 直接用于签到， 还会自动同步一份独立设备指纹（每个账号一份，共用会触发风控）。
高级：手动填写滑块凭证（滑块拉不起来时用）
格式为 滑块token:当次指纹c。填了就直接跳过自动滑块。

设置

两个入口分开排期，各在自己的窗口里随机挑一个时刻跑：续期 + 签到 + 刷新状态。
实际执行时间 = 起点 + 0～N 分钟内的随机值，每天都不同，避免固定时刻被风控识别。默认起点 08:00、浮动 60 分钟，即每天落在 08:00–09:00 之间。
APP 端默认排在 09:30 之后，和小程序入口错开，避免同一设备两个活动连着命中。同一账号的两个时间至少相差 5 分钟。
续期或签到失败时推一条消息，避免静默失效。
Bark 填 https://api.day.app/DeviceKey（自建服务填你的域名/key）；企业微信填群机器人 webhook 地址。类型自动识别，不用选。
APP 入口要求 X-LF-DXRisk-Token 是 App 内生成的真实指纹，否则会回 801810／8040012 这类误导性报错。
每个账号必须用不同的指纹——同一指纹用于多个账号会触发风控。重装 App 会生成新指纹；Mac 上跑 python tools/read_mac_app.py 可直接读出。没配指纹时会跳过 APP 入口，共用指纹的账号会被暂停签到。

签到时间

两个入口分开跑，时间至少相差 5 分钟。随机浮动沿用在「设置」里配的值。
